    Cấu Hình Link Web GitHub Pages Của Bạn

    Miễn phí 100% & Băng thông không giới hạn

    Nhập đường dẫn GitHub Pages sau khi bạn tải file index.html lên GitHub (VD: https://ten-cua-ban.github.io/autocut-studio/):

    Hướng Dẫn 5 Bước Tạo Link Web Riêng Trên GitHub Pages:

    1. Lưu toàn bộ mã nguồn ứng dụng này thành 1 file duy nhất tên là index.html trên máy tính.
    2. Đăng nhập github.com → bấm dấu + góc trên phải → chọn New repository → đặt tên (VD: autocut-studio) → chọn Public → bấm Create repository.
    3. Bấm Add file → Upload files → kéo thả file index.html vào → bấm nút xanh Commit changes.
    4. Vào tab Settings của Repository → chọn mục Pages ở menu bên trái → tại phần Branch đổi từ None sang main → bấm Save.
    5. Đợi 30 giây và tải lại trang, GitHub sẽ cấp cho bạn đường dẫn web riêng (dạng https://ten-cua-ban.github.io/autocut-studio/). Bạn chỉ cần gửi link này kèm tài khoản con đã tạo ở Tab 1 cho khách hàng!
